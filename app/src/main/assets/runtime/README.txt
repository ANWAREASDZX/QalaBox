حزمة وقت التشغيل — قلعة بوكس
=============================

هذا المجلد مخصص للبناء أثناء التجميع (اختياري):
ضع هنا مكوّنات وقت التشغيل الثنائية وستُشحن داخل APK مباشرة،
أو ثبّتها لاحقاً من داخل التطبيق عبر ملف .qbxruntime (الأفضل).

البنية المطلوبة (للحزمة .qbxruntime — ملف ZIP):
  imagefs.tar      نظام جذر Debian arm64 يتضمن:
                     - Wine (32بت) ملفوفاً بـ Box86/Box64 (أوامر wine تعمل مباشرة)
                     - box86 + box64
                     - Mesa (llvmpipe) + libx11 + libxfixes + libxtst
                     - Xvfb + PulseAudio + pactl
                     - gcc (اختياري — لبناء qalarender على الجهاز)
  proot            ثنائي proot ثابت arm64
  xserver/qalax11  (اختياري) خادم X مبني لأندرويد — يعطي أداء أعلى
  dxwrapper/cnc-ddraw/ddraw.dll  (اختياري لكن موصى به بشدة)
  dxwrapper/dxvk/  (اختياري) مكتبات DXVK
  version.json     {"version": "1.0.0", "notes": "..."}

راجع docs/RUNTIME_BINARIES.md للتعليمات الكاملة لبناء كل مكوّن
ومصادره المفتوحة وتراخيصه.

ملاحظة: ملفات وقت التشغيل لا تُشحن افتراضياً (الحجم + التراخيص) —
التطبيق يعمل بكامل بنيته وسيعمل فور توفير الحزمة.
