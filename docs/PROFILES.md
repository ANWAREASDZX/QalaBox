# دليل كتابة بروفايل لعبة جديدة

أي لعبة Windows جديدة = ملف JSON واحد في `app/src/main/assets/profiles/`.
التطبيق يحمّله تلقائياً في شاشة الألعاب عند الإقلاع التالي.

## الهيكل الكامل مع الشرح

```jsonc
{
  "id": "معرف_فريد_لاتيني",            // يُستخدم في حفظ إعدادات اللعبة
  "name": "Game Name",                  // الاسم الأصلي
  "nameAr": "الاسم المعروض",            // يظهر في الواجهة
  "icon": "",                           // فارغ = يُعرض أول حرف من الاسم
  "exeCandidates": ["Game.exe"],        // مرشحات الإقلاع بالترتيب —
                                        // يُبحث عنها تلقائياً في drive_c كله
  "arch": "auto",                       // auto (موصى به) | x86 | x64
  "env": {                              // متغيرات بيئة إضافية (اختياري)
    "BOX86_DYNAREC_STRONGMEM": "1"
  },
  "dxWrapper": "cncddraw",              // cncddraw | wined3d | dxvk
  "cnc_ddraw_overrides": {              // تُكتب فوق ddraw.ini تلقائياً
    "renderer": "opengl",
    "maxfps": "60",
    "fullscreen": "true",
    "hook": "3",
    "noactivateapp": "true"
  },
  "registry": [                          // مفاتيح تسجيل تُطبق قبل الإقلاع
    {
      "key": "HKCU\\Software\\MyGame",
      "value": "Path",
      "type": "REG_SZ",
      "data": "C:\\Games\\MyGame"
    }
  ],
  "launchArgs": "",                      // وسائط سطر الأوامر (مثل "-w")
  "fixes": [                             // الإصلاحات المطبقة (تُعرض للمستخدم)
    "وصف الإصلاح الأول"
  ],
  "preset": "balanced",                  // fast | balanced | compat
  "notesAr": "سطر تعريفي قصير"
}
```

## إرشادات الضبط حسب نوع اللعبة

| نوع اللعبة | dxWrapper | maxfps | STRONGMEM | ملاحظات |
|---|---|---|---|---|
| DirectDraw ثنائية الأبعاد (1997–2003) | cncddraw | 60 | 1 | الغالبية الساحقة |
| 3D مبكرة (DirectX 7–8) | wined3d | 60 | 1 | جرّب dxvk إن كان الجهاز قوياً |
| حساسة للتوقيت (منافذ LAN محلية) | cncddraw | 60 | 2 | نمط compat |
| تعتمد CWD بشكل صارم | أي | — | — | التطبيق يقرأ المجلد تلقائياً |

## خطوات الاختبار الموصى بها

1. أنشئ حاوية win32 بدقة 1280×720 مع cnc-ddraw
2. انسخ ملفات اللعبة إلى `drive_c/Games/اسم اللعبة` (استيراد ZIP من تبويب الملفات)
3. أضف البروفايل ثم اضغط تشغيل — راقب رسائل الإصلاحات
4. إن ظهرت شاشة سوداء: جرّب `hook` بين 1–4، أو `renderer=gdi`
5. إن تجمدت: ارفع STRONGMEM إلى 2 (نمط أقصى توافق)
6. شارك البروفايل مع المستخدمين — ملف واحد جاهز للاستيراد

## ملاحظات تقنية

- البحث عن exe يتجاهل حالة الأحرف ويغطي drive_c بكامل عمقه (حتى 8 مستويات)
- `apply_registry.sh` يُنشأ ويُنفذ ويُحذف تلقائياً في كل إقلاع يحتاج مفاتيح
- البروفايل لا ينسخ ملفات dll إلا عبر غلاف DirectX (نظافة مجلد اللعبة)
- المسار النسبي المخصص للمستخدم (من حوار «المسار التنفيذي») يُحفظ تلقائياً
