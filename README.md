# قلعة بوكس (QalaBox) v1.1

محاكي ألعاب استراتيجية لأندرويد بأسلوب **ExaGear Strategies** تماماً — لكن بمحرك أحدث
وأقوى، وبنية مفتوحة، وعلاجات مدمجة لكل أخطاء ExaGear المعروفة.

```
┌──────────────────────────────────────────────────────────────┐
│                     واجهة عربية كاملة (RTL)                  │
│   الألعاب • الحاويات • مدير الملفات • الإعدادات               │
├──────────────────────────────────────────────────────────────┤
│  محرك البروفايلات + إصلاحات الألعاب التلقائية                 │
│  (cnc-ddraw • توجيه الأنوية • معايرة المترجم • الصوت)         │
├──────────────────────────────────────────────────────────────┤
│  الجسر الأصلي (xbridge.c + qalarender.c)                      │
│  التقاط الإطارات • مؤشر عتادي • إدخال XTest • صوت PCM         │
├──────────────────────────────────────────────────────────────┤
│  Wine (طبقة Windows)  +  Box86/Box64 (مترجم x86→ARM)          │
│  proot (عزل)  •  Xvfb (عرض افتراضي)  •  PulseAudio (صوت)      │
├──────────────────────────────────────────────────────────────┤
│                    Android 10+ • ARM64                        │
└──────────────────────────────────────────────────────────────┘
```

## ما الجديد في v1.1 (اختبار شامل وإصلاحات جوهرية)

مراجعة عميقة بفحص آلي (gcc بلا تحذيرات + اتساق الموارد + XML/JSON/Shell) أعادت **34 إصلاحاً وتحسيناً** موثقة بالكامل في [docs/FIXES.md](docs/FIXES.md) — أبرزها:

- **تحجيم الإطار letterbox** بدل القصّ على شاشات النسب الطويلة (وتطابق المؤشر معه)
- **إصلاح علوق زر الفأرة** من مؤقّت الضغط المطوّل في لوحة اللمس
- **جسر إطارات يعمل مع خادم X المخصص** (كان غائباً — لا صورة بدون هذا الإصلاح)
- **علاج الأنوية الكبيرة أصبح فعّالاً** (taskset الآن داخل proot — كان معطلاً تماماً)
- **rootfs سليم** عبر دعم الروابط الرمزية والأسماء الطويلة (PAX/GNU) في مستخرج TAR
- **صيغ WINEDLLOVERRIDES الصحيحة** + اختيار wine64 تلقائياً لألعاب 64-بت
- تزامن البروتوكول، أمان المسارات (Zip/Tar Slip)، سقف ذاكرة السجل، منع نوم الشاشة، تنظيف الجلسة عند سحب التطبيق، وحماية من تلف الحزم
- ميزات جديدة: دقة الجهاز الأصلية، نمط أداء لكل لعبة، زر للأعلى في الملفات، حوارات التراخيص والتنبيه القانوني

## لماذا هذا المشروع وليس ExaGear؟

| المشكلة في ExaGear Strategies | حلها في قلعة بوكس |
|---|---|
| تطوير متوقف منذ 2019 ومصدر مغلق | مبني على Wine + Box64 نشطين التطوير |
| تقطيع الصوت المزمن | تدفق PCM عبر Simple-TCP مع تخزين مؤقت مضبوط |
| بطء المؤشر | مؤشر عتادي عبر XFixes + توجيه للأنوية الكبيرة |
| الشاشة السوداء في ألعاب DirectDraw | غلاف cnc-ddraw يُنشر ويُضبط تلقائياً لكل لعبة |
| لا توجد سجلات عند الفشل | سجل جلسة كامل قابل للتصدير بضغطة |
| الحاويات محدودة بلا نسخ احتياطي | إنشاء/حذف/نسخ/استعادة كاملة |
| الحاجة لنسخ مختلفة (RPG/Strategies) | كشف معمارية exe تلقائياً (PeParser) واختيار Box86/Box64 |
| تجمّد اللعبة عند مغادرة التطبيق | خدمة أمامية + Wake Lock |
| لا دعم للمعماريات الجديدة (ARMv9) | Box64 يتطور باستمرار وتُحدّث الحزمة |

> **تنبيه قانوني**: قلعة بوكس لا تتضمن ولا توزع أي ألعاب أو ملفات ExaGear.
> تحتاج نسختك الأصلية من كل لعبة. مكونات وقت التشغيل الثنائية (Wine/Box64…)
> تُبنى من مصادرها المفتوحة — راجع `docs/RUNTIME_BINARIES.md`.

## البدء السريع

1. افتح المشروع في **Android Studio** (Hedgehog أو أحدث) → `Build APK`
   — التفاصيل في `docs/BUILD.md`.
2. جهّز **حزمة وقت التشغيل** `.qbxruntime` — التعليمات الكاملة في
   `docs/RUNTIME_BINARIES.md` (ساعة عمل لمن يعرف سطر الأوامر).
3. من التطبيق: الإعدادات ← **تثبيت وقت التشغيل** ← اختر الحزمة.
4. الحاويات ← **حاوية جديدة** (win32 + cnc-ddraw + 1280×720).
5. الملفات ← **استيراد ZIP** ← ضع ملفات لعبتك في `drive_c/Games`.
6. الألعاب ← **سترونغهولد كروزيدر** ← تشغيل. استمتع.

## المسار التقني لماذا الأداء أفضل؟

- **Box64/Box86 (2026)** بمترجم JIT حديث مقابل محرك ExaGear المتجمد منذ 2019.
- **توجيه تنفيذي للأنوية الكبيرة** — ExaGear كان يوزع على العنقود الصغير فيتقطع.
- **معايرات مترجم لكل لعبة** (أقصى أداء/متوازن/أقصى توافق) بدل إعدادات واحدة.
- **عرض عبر سطح أندرويد مباشرة** بلا طبقات تشفير/فك وسيطة.
- **صوت PCM خام** بتخزين مؤقت قابل للضبط بدل خلل ALSA القديم.
